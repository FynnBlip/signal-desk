# Signal Desk · 通话评测工作台

喂任意 wav，出真实 PQ 分。把「语料 → 声线 → TTS → 信道 → 降噪 → 评测 → 判定」
七步通话测试链路做成可交互的本地工作台，零 GPU、纯 CPU 可跑。

> 目标：开源的、任何人一条命令能跑起来的通话质量评测工具。

## 当前状态

- ✅ 01 语料生成（已点亮，可在总览页交互）
- ⬜ 02~07 待施工（按蛋糕顺序一块一块点亮）

## 目录地图（第一层自解释）

| 目录 | 用途 |
|---|---|
| `app/` | 前端工作台（HTML，总览 + 各模块下钻） |
| `server/` | 本地后端服务（把 modules 挂成 HTTP 接口） |
| `modules/` | 七块蛋糕，编号 = 链路顺序 |
| `data/` | 数据资产（红线见 data/README.md） |
| `models/` | 模型下载指引（权重不入仓库） |
| `docs/` | ADR / 口径 / 踩坑记录 |
| `tests/` | 每块模块的验收测试 |

## 怎么跑

```bash
python server/main.py
# 浏览器打开 http://127.0.0.1:8090
```

# 八块蛋糕 · 模块地图

编号 = 真实通话链路的顺序。每块先做到「功能完备」再点亮，最后串成双闭环。

| 编号 | 模块 | 职责 | 功能完备 = |
|---|---|---|---|
| 01 | 语料生成 | 生成中文通话考试语料 + 易混音对覆盖自检 | 总览页可触发、可见结果 |
| 02 | 音色聚类 | 声线特征 + KMeans + 覆盖矩阵 | 上传/选择音色出聚类与矩阵 |
| 03 | TTS 合成 | 按音色合成 exam wav | 语料 × 音色批量合成、可试听 |
| 04 | 信道仿真 | Opus 编解码闭环（VoIP/OTT），噪声/丢包后续接入 | 可配带宽/码率、seed 复现 |
| 05 | 降噪 DUT | GTCRN / DeepFilterNet3，version_spec 切换 | 页面上选模型版本并跑降噪 |
| 06 | 评测 | audiobox 出 PQ/PC/CE/CU | 批量出分、落盘 CSV、可溯源 |
| 07 | 闭环大脑 | 归因 → 迭代 → 判定 → 金标 | 一键跑闭环并产出结论报告 |
| 08 | 真机采集 | 手机/蓝牙麦真实人声采集 | 页面可采、可定级、可留痕 |

规则：不一次性全跑。一块验收通过，再切下一块。

08 是旁挂模块：产出 tier=real_device 的真机语料，**不参与 01–07 的晋级判定**，
只做生态效度方向校验。设计与边界见 `docs/ADR-004-真机采集.md`。

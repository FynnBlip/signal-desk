# ADR-002 · 第四块信道仿真（04 CHANNEL）

状态：已定（依据外部评审收敛）

## 背景

前三块已完成。04 负责把「干净参考 wav」变成「经过通话链路损伤后的 degraded wav」，作为 05 降噪 DUT 和 06 评测的输入。

## 第一版范围

1. 编解码：固定 Opus，用 ffmpeg 实现；覆盖 VoIP/OTT 通话（微信、会议、WebRTC）。
2. 噪声 + 音量扰动：复用旧项目 `simulate_channel.py` 逻辑（加噪、音量、逐段 RMS 归一化）。
3. 本版不做：真实包级丢包/PLC、时变 AGC、IR 混响、回声双讲、窄带频响独立维度、AMR/EVS/mSBC。

## 编解码口径（准确性）

- VoIP/OTT（微信、会议、WebRTC）→ Opus。
- 蜂窝 VoLTE/VoNR → AMR-WB / EVS（后续）。
- 蓝牙 HFP → mSBC / LC3（后续）。
- 评测结论只能表述为「覆盖 VoIP/OTT」，不得写成「代表蜂窝通话」。

## Opus 参数

- codec 固定为 `opus`。
- 带宽档：8k narrowband / 16k wideband / 24k super-wideband / 48k fullband，默认 16k wideband。
- 码率：8 / 16 / 32 kbps 三档，默认 16 kbps。
- 默认 VBR，CBR 通过 `-vbr off` 可选。
- 输入 32k（03 TTS 产物）自动重采样到目标 Opus 带宽（默认 16k）。

带宽 × 码率耦合约束（带宽与码率不能自由组合）：

| 带宽 | 建议码率范围 |
|---|---|
| 窄带 8k | 8~12 kbps |
| 宽带 16k | 16~24 kbps（默认 16 kbps） |
| 超宽带 24k | 24~32 kbps |
| 全频带 48k | 32~64 kbps |

默认档锁死「16k wideband + 16 kbps」；非默认组合超出上表时前端给提示。

## 级联顺序（固定）

```
干净 wav → 加噪 + 音量扰动（发送端麦克风）→ Opus 编码 → Opus 解码 → degraded wav
```

噪声在编码前；第一版没有传输丢包，后续丢包插在「编码 → 解码」之间。

另提供一条「仅编解码」对照链：干净 wav → Opus 编码 → Opus 解码 → only-codec wav（不加噪），供 06 把「噪声损伤」与「Opus 编码损伤」分开归因。

## 目录与接口

- 03 输出统一到 `data/exam/`（修正当前 `tts.py` 实际写 `data/tts/` 的不一致）。
- 04 输出统一到 `data/matrix/`（唯一源）。
- 04 的 CSV/manifest 每条必须含 `reference` 字段，指向输入干净 wav，供 06 做 reference/degraded 配对评测。
- manifest 含 codec、带宽、码率、VBR/CBR、seed、SNR 设定/实测、输入输出路径、时长。

## 参数落盘（数据红线）

- SNR 记「设定 + 实测」两列；沿用逐段 RMS 归一化，避免设定与实测偏离。
- 码率记「设定 + 实测」两列：VBR 下 `-b:a` 是目标平均码率，实际会浮动，实测码率从编码后 `.opus` 用 ffprobe 读 `bit_rate`。
- seed 写入 CSV 与文件名。
- codec 字段预留，本版只填 `opus`。
- 带宽档、码率、VBR/CBR 一并落 CSV。

## 技术选型

- 编解码：ffmpeg CLI（Opus 全带宽/码率）。
- 噪声/增益：复用 `simulate_channel.py`（soundfile + numpy）。
- 依赖：ffmpeg 为外部二进制，README 与启动脚本需补安装说明。
- 不把「纯 CPU」当硬约束，可留 GPU 加速位，但保持本地可复现。

## 实施顺序（闯关式）

1. 第一步：Opus 编解码闭环，点亮 04。
2. 第二步：接入噪声 + 增益，组成固定 pipeline「加噪 → 编解码」。
3. 第三步（第二层）：丢包 / 抖动 / PLC，改用 libopus 或 opus-tools，单独验收。

## 验收标准

- 04 可对任一 `data/exam/` 下的干净 wav 生成 degraded wav 与可追溯 CSV。
- 04 单块可验收：对任一 `data/exam/` 下干净 wav 生成 degraded wav（含仅编解码对照）与可追溯 CSV。
- 「03 → 04 → 05 链路跑通」标为「待 05 就绪后的联调项」，不放在当前验收。
- 所有数字来自真实 CSV，不写死、无假数据。
- 带宽、码率、seed 随结果标注。
